# Context Template

Create one directory from this template for each owned context. Fill in the owner, communication topology, data invariants, published contract, and validation adapter before implementation.

Suggested files:

- `CONTEXT.md` — purpose, owner, owned paths, collaborators, and dependencies
- `contract.md` — public data shapes and compatibility rules
- `data-model.md` — canonical data and invariants
- `testing.md` — unit, contract, property, and fuzz targets
